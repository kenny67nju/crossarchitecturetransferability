感谢审稿人认可该问题的重要性、理论诊断、实践设计、实验覆盖范围以及复现材料。我们同意，原稿应当更明确地说明算法流程、参考集选择、适用规则，以及几何前提的经验性质。

## 1. 逐步算法与异构特征维度

"固定参考编码器"这一表述容易造成误解，我们的表达方式很可能是误解的来源。准确地说：我们固定的是参考**数据集** R（主实验中为 STL-10），而不是所有候选模型共用的某个编码器。

对于每个候选编码器 m，由同一个编码器同时处理目标图像和参考图像，得到中心化的目标特征 H_(m,T)（形状 n_T × d_m）和参考特征 H_(m,R)（形状 n_R × d_m）。

因此，在每次 alignment 计算中，两组特征的维度完全相同。不同候选可以具有不同的 d_m，但它们的右奇异子空间不会相互比较。方法不需要公共特征空间或跨编码器投影。

对于中心化后的特征矩阵，令 H_(m,T) = U_T Σ_T V_T^⊤ 和 H_(m,R) = U_R Σ_R V_R^⊤ 为两者的 SVD，且 k_m = min(k, n_T, n_R, d_m)。实际实现的 alignment 为

```
SA_k(H_(m,T), H_(m,R)) = (1/k_m) · ‖V_T^⊤ V_R‖_F²
                       = (1/k_m) · Σ_{i=1..k_m} cos²(θ_i),
```

其中 θ_i 是候选模型 m 自身 d_m 维表示空间中两个主右奇异子空间之间的 principal angle。

紧凑的算法流程如下：

```
输入：候选编码器 m、目标任务 T、参考集 R、子空间大小 k
1. H_T   <- 用 m 提取并中心化目标特征
2. H_ref <- 用 m 提取并中心化参考特征
3. V_T   <- H_T 的前 k_m 个右奇异向量
4. V_ref <- H_ref 的前 k_m 个右奇异向量
5. SA    <- ||V_T^T V_ref||_F^2 / k_m
6. p_i   <- sigma_i(H_T) / sum_j sigma_j(H_T)
7. r_eff <- exp(-sum_i p_i log p_i)
8. score <- (log r_eff - log SA) / log C(T)
输出：score
```

因此，effective rank 和最终实验分数为

```
p_i = σ_i / (Σ_j σ_j),
r_eff(H) = exp( −Σ_i p_i · log p_i ),

SSR‡(H, T) = [ log r_eff(H) − log SA_k(H, H_ref) ] / log C(T).
```

跨候选模型只比较返回的标量分数。这就是异构特征维度不需要额外投影机制的原因。

## 2. STL-10 不适用时如何选择参考集

STL-10 是实践默认选择，而不是理论最优参考集。选择它是因为规模较小、包含多样的自然物体、所有候选模型都能处理，并且与七个非 STL-10 的 VTAB 目标任务相互独立。

当 STL-10 不可用或不适合时，建议按照以下顺序选择：

1. **与目标相互独立：**不能用被评估的目标数据集作为自身参考集。
2. **不使用目标性能选择：**不能根据目标标签或目标准确率选择、调节参考集。
3. **模态兼容：**选择与部署领域属于同一大类模态的数据，如自然图像、医学图像或遥感图像。
4. **覆盖广而非领域窄：**优先选择多样、通用的内容，而不是高度任务特化的数据。
5. **可稳定估计：**样本应足够多且足够多样，以估计前 k 个子空间方向。
6. **所有候选均可用：**每个候选模型都必须能通过相同特征接口处理该参考集。

参考集可以考虑下游领域的大类性质，但必须独立于下游性能进行选择。否则，参考集选择本身会变成有监督模型选择过程。

VTAB 消融说明了这一权衡。使用 STL-10 时 SSR‡ regret 为 0.066，CIFAR-10 为 0.098，四参考中位数为 0.051。Flowers-102 为 0.013，但它本身就是目标任务；这一异常低值反映目标/参考泄漏，而不是有效优势。

## 3. 是否默认使用多参考集成，以及额外成本

单参考方案对每个候选模型增加一次无标签参考侧特征提取。参考特征只需计算一次，可以缓存并复用于所有目标任务。如果使用 M 个参考集，参考侧计算和存储成本近似增加为 M 倍；目标侧成本不变。对缓存后的 alignment 取中位数，相对于特征提取的成本可以忽略。

四参考集成将 VTAB regret 从 0.066 改善至 0.051，但该提升不足以证明所有部署都必须使用四个参考集。因此我们的建议是：

- 默认：一个通用、target-disjoint 的参考集；
- 对鲁棒性要求较高的场景：使用预先确定的小规模参考集成，并取中位数；
- 绝不能把被评估目标包含在其自身参考集合中。

这既保留默认方法的轻量性，也在参考敏感性较重要时提供明确选项。

## 4. 实践决策规则：SSR‡ 还是 RankMe？

我们同意原稿缺少清晰的实践决策规则。SSR‡ 不是 RankMe 的通用替代品。

- **异构架构 family 之间：**使用 SSR‡。这是宽度变化并导致 RankMe 混淆的场景。
- **单一架构 family 内：**使用 RankMe。此时模型维度和主子空间相近，alignment 项无法提供稳定的额外信号。
- **每个 family 包含多个 variant 的混合模型库：**先用 SSR‡ 选择 family，再用 RankMe 选择 family 内的 variant。

在五任务 MV 多变体基准上，flat SSR‡ 的 regret 为 0.098，平均成本为 118.8；SSR‡ → RankMe 的 regret 为 0.102，平均成本为 38.0。这支持该两阶段分工在 MV 上的可行性，但我们同意五个任务只能构成 proof of concept，不能作为一般 cost-quality 保证。

## 5. 几何前提的证据性质

我们同意，目前不存在从 SA_k 到 linear-probe accuracy 的形式化界。相关证据应被描述为经验机制，而不是下游性能定理。

在 126 个 VTAB 架构—任务 pair 上，SA_k 与通用参考子空间之外的类间方差比例高度负相关（ρ = −0.964）。该架构特异性方差比例又能正向预测 LP accuracy。这解释了减去 alignment 为什么可能有效，但不能保证方法在所有模型池或所有 family 内成功。

## 6. 相对 DiSCO 的最新结论范围

内部核查确认，官方 DiSCO 使用目标真实标签构造类条件量。因此它是需要标签的比较方法，而不是 label-free baseline。我们还按照官方 PCA-128 流程重新实现，并补齐所有缺失特征和 LP 单元。为了与下文的共同任务集合保持一致，VTAB 数值排除 STL-10；其他模型池使用各自完整的目标任务集合。修正后的 G=6/G=8 regret 为：MV 0.146/0.146、VTAB（7 个目标；排除 STL-10）0.061/0.044、SSL 0.045/0.042、EX 0.045/0.049。

这些结果说明 DiSCO 比原稿报告的更强，尤其是在 EX 上。因此我们撤回"SSR‡ 普遍优于 DiSCO"的主张。公平的相同标签预算比较仍然是 SSR‡ 与 RankMe。在统一排除 STL-10 目标任务后的 22 个共同任务单元上，两者 regret 分别为 0.071 和 0.166；配对差值为 −0.095，95% CI 为 [−0.160, −0.037]，采用双侧、任务级 paired bootstrap 检验得到 p = 0.0002。

综上，合理的结论范围是：SSR‡ 是一种针对跨 family 宽度混淆的轻量、无超参数、无标签校正。RankMe 在单一 family 内仍然适用；参考集选择以及 alignment 与下游准确率之间的联系仍是经验限制；两阶段结果只应在已评估基准范围内解释。
