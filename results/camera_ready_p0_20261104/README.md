# P0-corrected camera-ready assets (2026-11-04)

Canonical repair arm: `single_preprocess_4096` in `../p0_vgg_pair_20261104/p0_aggregate_v2/`. The original P0 bundle and prior `results/camera_ready/` outputs are preserved, not overwritten. This directory contains new manuscript-facing derivatives, not a replacement experiment archive.

## Supports and limitations

- Headline: MV 119 candidates / 5 tasks, VTAB 24 architectures / 7 non-reference targets, EX 51 candidates / 10 tasks; 22 pool-task units and 10 unique target names. SSL is not part of this aggregate.
- Auxiliary MV comparisons: remove `efficientnet_b2.ra_in1k` on every task because its inherited CIFAR-10 auxiliary scores are missing; 118 candidates. The matched VGG-removal diagnostic uses 115. These supports must not be conflated with headline 119 or full-inventory 132.
- New VGG16 and VGG16-BN features use retained hidden fully connected layers (4096 dimensions) and one official weights transform. Other 650 inventory rows remain frozen. This is not a full-zoo extraction rerun.
- Raw repair caches and weights remain on the server. Historical original cache provenance is incomplete; no claim of a fully public, end-to-end reproducible archive is made.

## Files and reproduction

`paper_values.json` records input SHA256 values, headline statistics and width-figure data provenance. `numeric_acceptance.json` records the independent numerical/source-integrity audit (502 checks). `pdf_acceptance.json` records the PDF structure/font/link/metadata audit. The latest prose/visual review is documented in `docs/CAMERA_READY_FINAL_ACCEPTANCE_20261104.md`; the prior reader-review and P0 acceptance records are preserved.

`code/review_followup_diagnostics.py` derives the added stage comparisons and score correlations from immutable P0 scores. Its outputs are in `results/camera_ready_review_20261104/`. The default asset builder also runs it. The UID-normalized score is not raw UID. Both new stage rows use the 119-candidate headline support with all 35 canonical scores available.

From the repository root, using a Python environment with NumPy, pandas, SciPy and Matplotlib:

```sh
python3 code/build_p0_camera_assets.py
python3 code/figure_sigma_b_flow.py
python3 code/audit_p0_manuscript.py
```

With XeLaTeX, BibTeX and Poppler on PATH, and Python with pypdf:

```sh
python3 code/build_camera_ready_pdfs.py --language both
python3 code/audit_camera_ready_pdfs.py
```

The default delivery is `paper/Paper06_camera_ready_en.pdf` or `paper/Paper06_camera_ready_zh.pdf`: each contains the complete paper, disclosures, references, appendices and finally the checklist, with internal links. The `combined` filenames are byte-identical compatibility aliases. Separate supplement PDFs are optional appendix-only extracts, not required companion files. Legacy filenames such as `paper/main_v18.pdf` are not regenerated by this build. The figure compatibility wrappers call the canonical asset builder instead of regenerating historical hard-coded numbers.

Statistical protocol: 100,000 bootstrap resamples, seed 42; target-name clusters retain all corresponding pool units and compute a unit-weighted mean. Wilcoxon uses paired differences rounded to 10 decimal places, `zero_method='wilcox'`, `method='approx'`, two-sided, no continuity correction; reference SciPy 1.15.3.

No external upload, repository push, or conference submission is performed by these scripts.
