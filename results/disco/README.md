# Corrected official DiSCO results

The `*_official_pca128_g{6,8}.csv` files contain scores from the corrected
official class-conditional Mahalanobis-posterior implementation with PCA-128.

Run:

```bash
python3 code/summarize_official_disco.py
```

This reproduces `official_disco_regret_summary.csv`. The VTAB summary excludes
STL-10 so that its support matches the 22-task rebuttal comparison; MV and EX
use all their target tasks.

The top-level `results/cross_pool_regrets.csv` and the `disco` columns in the
older top-level pool CSVs were generated by the legacy approximation. They must
not be used to reproduce the corrected official-DiSCO rebuttal table.
